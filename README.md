## Sobre o projeto

Esse portfólio nasceu da vontade de ter um lugar que realmente tivesse a minha identidade.

Mais do que uma página para listar tecnologias ou projetos, a ideia foi criar uma experiência que mostrasse um pouco da minha personalidade, da minha forma de trabalhar e da maneira como enxergo desenvolvimento e tecnologia.

Por isso, o site tem uma abordagem mais visual e interativa, com animações, elementos personalizados e uma navegação pensada para fugir um pouco do padrão de portfólios tradicionais.

## 🎨 Design

Uma das principais preocupações durante o desenvolvimento foi não deixar o site com aquela aparência de "template de portfólio".

A interface foi construída buscando uma identidade própria, misturando:

* tecnologia
* elementos visuais
* animações
* referências pessoais
* experimentação

O objetivo é que a pessoa consiga entender um pouco de quem está por trás do código simplesmente navegando pelo site.
